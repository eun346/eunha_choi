# FaceOnOff

CourtVision is a basketball video-analysis project developed for CSE 327. It uses YOLO-based detection and object tracking to identify players, the ball, referees, and court regions, while assigning player IDs across frames. The system also detects events such as jump shots and layups/dunks and associates them with the involved player.
