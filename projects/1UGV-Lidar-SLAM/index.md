# UGV LiDAR–Inertial SLAM

This project explores whether repeated LiDAR–inertial maps captured by an unmanned ground vehicle can reveal structural changes in an environment. I organized the sensing, mapping, and comparison workflow into a technical poster while studying how mobile mapping can support structural monitoring.
